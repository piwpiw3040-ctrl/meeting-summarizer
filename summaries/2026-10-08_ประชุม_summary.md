## ⚖️ มติที่ประชุมและข้อตกลงร่วมกัน (Decisions & Key Agreements)
- **การฟื้นฟูระบบ 4 ไซต์งานเดิม:** ให้ติดต่อประสานงานไซต์งานเดิมทั้ง 3 แห่งที่ระบบออฟไลน์ (นครสวรรค์, นครศรีธรรมราช, ฉะเชิงเทรา) หากต้องการใช้งานต่อ บริษัทจะออกค่าซิมอินเทอร์เน็ตให้เพื่อดึงระบบกลับมาออนไลน์ แต่หากไม่ต้องการใช้ ให้วางแผนขออนุมัติย้ายไปติดตั้งให้หน่วยงานอื่นที่มีความต้องการ เช่น โรงเรียนคนตาบอด หรือสถานสงเคราะห์คนชรา
- **มาตรฐานการกำหนด Serial Number และ QR Code บนฮาร์ดแวร์:** ตกลงเปลี่ยนจากการระบุ ID/Token แบบแมนนวล มาเป็นการใช้ QR Code โดย Serial Number จะประกอบด้วยรหัสประเภทอุปกรณ์ (Device Type) ตามด้วยหมายเลขรันนิ่ง (Running Number) 6-7 หลัก เพื่อรองรับการสแกนจับคู่ผ่านแอปพลิเคชันทันที
- **การปรับปรุงกระบวนการ Provisioning ของแอป FarmBoss:** ปรับปรุง Flow การเชื่อมต่อและลงทะเบียนอุปกรณ์ โดยให้ผู้ใช้สแกน QR Code แล้วกดปุ่ม Pair ผ่าน BLE หรือเสียบสาย USB-OTG เพื่อส่งค่า Client ID/Token เข้าบอร์ดโดยตรง แทนการที่ผู้ใช้ต้องมากรอกโค้ดหรือจัดการหลังบ้านเอง
- **การจัดทำสื่อและคู่มือประกอบสินค้า:** ให้จัดทำตารางเปรียบเทียบคุณสมบัติ (Comparison Sheet/Brochure) ระหว่างบอร์ดอุตสาหกรรมของบริษัทกับบอร์ดราคาถูกทั่วไปในตลาด เพื่อใช้เป็นเอกสารขาย และทำคู่มือการติดตั้งแผ่นพับขนาดกะทัดรัด (1-2 หน้า) พร้อม QR Code ลิงก์ไปยังคู่มือฉบับเต็ม

## 📝 ประเด็นสำคัญแยกตามวาระการพูดคุย (Key Discussion Points)

### 1. การติดตามสถานะระบบ 4 จังหวัดและแนวทางดูแลลูกค้า (สนปช.)
- **สาระสำคัญ:** ระบบที่ติดตั้งให้หน่วยงานเกษตร/กลุ่มวิสาหกิจ 4 จังหวัด ปัจจุบันมีเพียงมหาสารคามที่ใช้งานได้ ส่วนที่อื่นระบบออฟไลน์ไปเนื่องจากครบกำหนดสัญญาดูแลรักษา 1 ปี ทำให้ซิมการ์ดอินเทอร์เน็ตถูกตัดสัญญาณ และเจ้าหน้าที่ท้องถิ่นไม่มีงบต่อซิมหรือไม่มีคนรับผิดชอบดูแลต่อ
- **ความคิดเห็น/ข้อเสนอแนะ:** 
  - หากปล่อยทิ้งร้างจะกระทบต่อภาพลักษณ์ของบริษัทและ สนปช. จนไม่สามารถใช้อ้างอิง (Reference) เพื่อของบทำเพิ่มอีก 70 ศูนย์ทั่วประเทศได้
  - เสนอให้บริษัทเติมเงินต่อซิมให้เอง (ค่าซิมปีละไม่กี่ร้อยบาท) หรือเสนอแพ็กเกจ Maintenance/Upgrade ระบบใหม่ (ระบบ AI ปุ๋ย/มอนิเตอร์) หากไซต์ใดไม่ใช้จริงๆ ให้เสนอของบ สนปช. รื้อถอนและย้ายโครงสร้างโรงเรือนไปมอบให้หน่วยงานอื่นที่พร้อมใช้งาน

### 2. การเปรียบเทียบผลิตภัณฑ์บอร์ด IoT กับสินค้าในท้องตลาด
- **สาระสำคัญ:** มีการนำบอร์ด ESP32 รีเลย์ 4 ช่อง ราคาประมาณ 597-800 บาทในท้องตลาดมาเปรียบเทียบกับบอร์ดของบริษัท ซึ่งมีราคาสูงกว่ามาก (เกือบ 7,000 บาท)
- **จุดเด่นของบอร์ดบริษัทที่เหนือกว่า:**
  - **คุณภาพเกรดอุตสาหกรรม (Industrial Grade):** อุปกรณ์และชิปทนทานต่อความร้อนและการแฮงก์
  - **คุณภาพรีเลย์:** ใช้ Power Relay เกรดสูง ทนกระแสตัดต่อได้ดี ไม่เกิดปัญหาหน้าสัมผัสอาร์ก (Arc) หรือไหม้จนติดขัดเมื่อใช้กับไฟ DC หรือโซลินอยด์วาล์ว
  - **วงจรในตัว (Built-in Components):** มีพอร์ตสื่อสาร RS-485 สำหรับต่อเซนเซอร์อุตสาหกรรม, ตัวขยายพอร์ต และมีโมดูล RTC (Real-Time Clock) ตั้งเวลาได้เองแม้ไม่มีอินเทอร์เน็ต ขณะที่บอร์ดราคาถูกใช้เน็ตซิงก์เวลาอย่างเดียว
  - **เสาอากาศ:** ใช้เสาภายนอก (External Antenna) ส่งสัญญาณได้ไกล 50-100 เมตร (บอร์ดตลาดเป็น PCB Antenna ส่งได้เพียง 10-15 เมตร)
- **ข้อเสนอแนะ:** ต้องทำเอกสารสเปกชีตเปรียบเทียบให้ชัดเจน และออกแบบให้แอป FarmBoss สามารถรองรับบอร์ดตลาดราคาถูกได้ด้วย เพื่อเจาะกลุ่มโรงเรียน/นักศึกษา โดยขายเป็น License ซอฟต์แวร์แทน

### 3. การปรับปรุงกระบวนการติดตั้งและลงทะเบียนอุปกรณ์ (Device Provisioning)
- **สาระสำคัญ:** ปัจจุบันขั้นตอนการบันทึก ID และ Token ของอุปกรณ์มีความซับซ้อน ต้องทำผ่านเซิร์ฟเวอร์ก่อน ทำให้เกษตรกรหรือช่างหน้างานทำเองไม่ได้
- **แนวทางแก้ไข:**
  - สร้างระบบ Provisioning ผ่านมือถือ: อุปกรณ์ที่ผลิตเสร็จจะมี Serial Number และ QR Code ติดที่กล่อง
  - ผู้ใช้เปิดแอป FarmBoss สแกน QR Code แล้วกดปุ่ม Pair (กดค้าง 5 วินาที) แอปจะเชื่อมต่อบอร์ดผ่าน BLE หรือสาย USB-OTG จากนั้นแอปจะไปดึง Client ID และ Token จากเซิร์ฟเวอร์มาเบิร์นลงบอร์ดอัตโนมัติ
  - หากการเบิร์นไม่สำเร็จ ให้ระบบทำ Rollback ข้อมูลบนเซิร์ฟเวอร์เพื่อไม่ให้เกิดขยะในฐานข้อมูล
  - วางระบบให้เซนเซอร์มาตรฐานเชื่อมต่อแล้วพร้อมใช้งานได้ทันที (Plug & Play) ผ่านการตั้งค่า Default ในเฟิร์มแวร์

### 4. การพัฒนาระบบสถานีตรวจอากาศ (Weather Station) และกล้องวงจรปิด
- **สาระสำคัญ:** มีการทดสอบเชื่อมต่อสถานีตรวจอากาศเข้ากับระบบควบคุมโรงเรือนเพื่อดึงค่ามาตั้งเงื่อนไขการทำงาน และพูดคุยถึงความต้องการติดกล้อง CCTV ส่องดูแปลงเกษตร/ทุเรียน
- **แนวทางเชิงเทคนิค:**
  - การต่อกล้องเข้ากับสถานีตรวจอากาศ ESP32 มีข้อจำกัดด้านแบนด์วิธและการประมวลผล
  - เสนอแนวคิดการใช้บอร์ด Raspberry Pi (เช่น CM5 / Pi 5) มาทำเป็น Edge AI Server สำหรับสถานีตรวจอากาศระดับสูง เพื่อรองรับการต่อกล้อง 2 ตัว, วิเคราะห์ภาพผู้บุกรุก/สภาพอากาศ และต่อชิปแปลง RS-485 เพื่ออ่านเซนเซอร์สภาพอากาศ

### 5. การเตรียมความพร้อมหน้างานและงานติดตั้ง (เพชรบูรณ์ - ร้อยเอ็ด)
- **สาระสำคัญ:** มีกำหนดการเดินทางไปติดตั้งงานช่วงวันที่ 12-15 ที่เพชรบูรณ์และร้อยเอ็ด
- **การเตรียมการ:**
  - จัดเตรียมพาหนะสำหรับขนย้ายโครงสร้างเหล็ก ท่อ บันได และเครื่องมือ โดยต้องเช็กขนาดสิ่งของเพื่อเลือกระหว่างรถกระบะหรือรถบรรทุก
  - มอบหมายให้ทีมที่เดินทางไปร้อยเอ็ด แวะตรวจสอบและเยี่ยมเยียนไซต์งานที่มหาสารคาม เพื่อบริการหลังการขายและถ่ายภาพอัปเดตระบบ

## ⚠️ ปัญหา อุปสรรค และความเสี่ยง (Blockers & Risks)
- **ความเสี่ยงโครงการภาครัฐถูกทิ้งร้าง:** ไซต์งานเดิม 3 ไซต์ไม่มีผู้ดูแลต่อเนื่องและซิมการ์ดหมดอายุ อาจส่งผลเสียต่อชื่อเสียงของบริษัทหากมีการเข้าตรวจสอบ
- **การใช้งานแอปพลิเคชันหน้างานเกิดข้อผิดพลาด:** มีรายงานปัญหาจากผู้ใช้งานเรื่องไม่สามารถควบคุมระบบน้ำ/ปุ๋ยได้ ซึ่งตรวจสอบเบื้องต้นพบว่าเป็นปัญหาฝั่งเซิร์ฟเวอร์และไลเซนส์ ต้องเร่งแก้ไขให้ระบบกลับมาทำงานได้ตามปกติ
- **ความคงทนของอุปกรณ์ในสภาพแวดล้อมจริง:** ความร้อนภายในกล่องควบคุมที่ตากแดดอาจสูงเกือบ 100 องศาเซลเซียส การออกแบบกล่องต้องกันน้ำ (IP65/IP68) และอาจต้องติดตั้งฮีตซิงก์ (Heat Sink) ช่วยระบายความร้อนให้ชิป ESP32
- **ความปลอดภัยของระบบ Provisioning:** มีการตั้งข้อสังเกตเรื่องการป้องกันการขโมยอุปกรณ์ หากมีปุ่ม Factory Reset ที่รีเซ็ตและนำไปใช้ต่อได้ง่ายเกินไป อาจเปิดช่องให้เกิดการโจรกรรมอุปกรณ์หน้าสวนได้

## 📅 การติดตามงานและนัดหมายครั้งถัดไป (Next Steps & Follow-up)
- **การติดตามผลทางเทคนิค:** เดียร์และเฟิร์มจะทดสอบการเขียนเฟิร์มแวร์ลงทะเบียนอุปกรณ์ผ่าน USB-OTG/BLE และสรุปผลการ Provisioning บนแอป FarmBoss
- **กำหนดการออกหน้างาน:** เตรียมความพร้อมอุปกรณ์และทีมงานเพื่อเดินทางไปติดตั้งงานที่เพชรบูรณ์และร้อยเอ็ด ระหว่างวันที่ 12-15 ของเดือนนี้
