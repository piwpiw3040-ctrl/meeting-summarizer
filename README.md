# 🎙️ Meeting Summarizer (ระบบสรุปเสียงบันทึกการประชุมอัตโนมัติ)

ระบบสรุปเสียงบันทึกการประชุมภาษาไทยสำหรับใช้งานส่วนบุคคล ขับเคลื่อนด้วย **Google Gemini 3.8 Flash** ทำงานแบบ Inbox Folder ลากไฟล์เสียงมาใส่แล้วกดรัน ได้ไฟล์บันทึกการประชุม Markdown (`.md`) ทันที

---

## ✨ จุดเด่นของระบบ
- **🧠 Native Multimodal:** ใช้ความสามารถของ Gemini ฟังเสียงโดยตรงโดยไม่ต้องแปลงเป็นข้อความก่อน (Whisper) ทำให้จับบริบท น้ำเสียง คำศัพท์เฉพาะ และภาษาไทยผสมอังกฤษได้อย่างแม่นยำ
- **⚡ รวดเร็วและฟรี:** ใช้ Gemini 3.8 Flash ผ่าน Google AI Studio ฟรีโควตาต่อวันสูงมาก
- **📁 โครงสร้าง Inbox อัตโนมัติ:** เมื่อสรุปเสร็จ จะย้ายไฟล์เสียงต้นฉบับไปที่ `completed/` เพื่อป้องกันการประมวลผลซ้ำ
- **📋 รูปแบบสรุปครบวงจร:** 
  - สรุปภาพรวมสำหรับผู้บริหาร (Executive Summary)
  - มติที่ประชุม / ข้อตกลงร่วมกัน (Decisions & Key Agreements)
  - **ตาราง Action Items** ระบุงาน, ผู้รับผิดชอบ, กำหนดส่ง (Deadline)
  - สรุปประเด็นสำคัญแยกตามวาระ/หัวข้อ (Key Discussion Points)
  - ความเสี่ยง ปัญหา หรืออุปสรรค (Blockers & Risks)
  - การนัดหมายและขั้นตอนถัดไป (Next Steps)

---

## 📂 โครงสร้างโฟลเดอร์

```text
meeting-summarizer/
├── audio/               <-- 📥 โยนไฟล์เสียงที่ต้องการสรุปไว้ที่นี่
├── completed/           <-- 📦 ไฟล์เสียงที่สรุปเสร็จแล้วจะถูกย้ายมาเก็บที่นี่อัตโนมัติ
├── summaries/           <-- 📄 ผลลัพธ์ไฟล์สรุป Markdown (.md) จะถูกบันทึกที่นี่
├── .env                 <-- 🔑 ไฟล์ใส่ GEMINI_API_KEY
├── summarizer.py        <-- โค้ดหลักของระบบ
├── run_summarizer.bat   <-- 🖱️ ดับเบิ้ลคลิกเพื่อรันบน Windows ได้ทันที
├── setup.bat            <-- ติดตั้งไลบรารีอัตโนมัติ
└── requirements.txt
```

## 🚀 ขั้นตอนการเริ่มต้นใช้งาน (3 ขั้นตอน)

### ขั้นตอนที่ 1: ขอ API Key ฟรีจาก Google AI Studio
1. ไปที่เว็บไซต์: [Google AI Studio (API Keys)](https://aistudio.google.com/app/apikey)
2. เข้าสู่ระบบด้วยบัญชี Google ของคุณ
3. กดปุ่ม **"Create API key"** แล้วคัดลอก (Copy) คีย์ที่ได้

### ขั้นตอนที่ 2: นำ Key มาใส่ในไฟล์ `.env`
เปิดไฟล์ `.env` ในโฟลเดอร์โปรเจกต์นี้ด้วย Notepad หรือ Text Editor แล้วใส่คีย์ของคุณ:
```env
GEMINI_API_KEY=AIzaSy...ของคุณที่นี่...
GEMINI_MODEL=gemini-2.5-flash
```

### ขั้นตอนที่ 3: โยนไฟล์เสียงแล้วกดรัน!
1. นำไฟล์เสียงการประชุม (เช่นไฟล์ `.m4a` จากแอปบันทึกเสียงในมือถือ, `.mp3`, `.wav` ฯลฯ) มาวางไว้ในโฟลเดอร์ `audio/`
2. **ดับเบิ้ลคลิกไฟล์ `run_summarizer.bat`** (หรือพิมพ์คำสั่ง `python summarizer.py` ใน Terminal)
3. ระบบจะประมวลผลและสร้างไฟล์สรุปในโฟลเดอร์ `summaries/` พร้อมย้ายไฟล์เสียงไปที่ `completed/` ให้ทันที!

## 🎧 นามสกุลไฟล์ที่รองรับ
- `.m4a` (ไฟล์บันทึกเสียง iPhone / Voice Memos ยอดนิยม)
- `.mp3`
- `.wav`
- `.aac`
- `.ogg`
- `.flac`
- `.mp4` / `.webm` / `.m4v` (สามารถส่งไฟล์วิดีโอที่มีเสียงได้เช่นกัน)

## 💡 ทิปการใช้งานเพิ่มเติม
- **เปิดไฟล์สรุป:** สามารถเปิดอ่านไฟล์ใน `summaries/` ได้ผ่าน Obsidian, Notion, VS Code หรือโปรแกรม Markdown Viewer ใดๆ ก็ได้
- **ปรับแต่งโครงสร้างสรุป:** หากมีหัวข้อเฉพาะทางที่ต้องการเป็นพิเศษ สามารถเปิดไฟล์ `summarizer.py` แล้วแก้ไขตัวแปร `SUMMARY_PROMPT` ได้อย่างอิสระ
